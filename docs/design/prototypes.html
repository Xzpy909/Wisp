Wisp: four ways to find a clip in under a second

Each screen below is a live mockup of the popup you'd get from Ctrl Shift V. Click one and just start typing. Arrows move, Enter pastes, Tab switches the type filter, Ctrl P pins, Esc clears. The clips are sample content, the same set in all four.
